# Đồ án Tin học --- DH52302277

Dự án học phần Công nghệ thông tin, phục vụ việc thực hành cấu trúc dữ
liệu, tư duy lập trình và xử lý dữ liệu.

## 1. Giới thiệu dự án

Đây là đồ án được thực hiện trong quá trình học ngành Công nghệ thông
tin. Repository lưu trữ mã nguồn liên quan đến `LinkedList`, các tệp dữ
liệu CSV/TXT và tài liệu báo cáo của đồ án.

## 2. Cấu trúc repository

  -----------------------------------------------------------------------
  Tệp / Thư mục                       Mô tả
  ----------------------------------- -----------------------------------
  `LinkedList/`                       Thư mục chứa các tệp mã nguồn liên quan đến thành phần danh sách liênnkết

  `BaoCaoDoAnTinHoc.docx`             Báo cáo đồ án

  `CTDL_CSV.txt`                      Tệp văn bản liên quan đến cấu trúc dữ liệu hoặc xử lý CSV

  `gpu_specs_v6.csv`                  Tập dữ liệu thông số GPU, phiên bản 6

  `gpu_specs_v7.csv`                  Tập dữ liệu thông số GPU, phiên bản 7

  `manifest.mf`                       Tệp manifest, có thể được tạo hoặc sử dụng trong quá trình đóng gói dự án
  -----------------------------------------------------------------------

## 3. Kiến thức áp dụng

-   Cấu trúc dữ liệu và tư duy lập trình.
-   Làm việc với dữ liệu có cấu trúc trong các tệp CSV/TXT.
-   Tổ chức mã nguồn và tài liệu dự án.
-   Sử dụng Git và GitHub để quản lý, lưu trữ mã nguồn.

## 4. Công nghệ sử dụng

Chỉ giữ lại những công nghệ thực sự được sử dụng trong mã nguồn.

-   **Ngôn ngữ lập trình:** C#
-   **Định dạng dữ liệu:** CSV, TXT
-   **Quản lý mã nguồn:** Git, GitHub

## 5. Hướng dẫn cài đặt và chạy

Cách chạy cụ thể phụ thuộc vào ngôn ngữ lập trình và cấu hình dự án.

1.  Clone hoặc tải repository về máy.
2.  Mở thư mục `LinkedList/` và xác định tệp khởi chạy chính.
3.  Cài đặt môi trường chạy Visual Studio Code.
4.  Chạy dự án theo hướng dẫn tương ứng với ngôn ngữ hoặc hệ thống build.


## 6. Những gì đã học được

-   Áp dụng cấu trúc dữ liệu vào bài toán lập trình.
-   Đọc, tổ chức và xử lý dữ liệu có cấu trúc.
-   Viết tài liệu và duy trì cấu trúc dự án.
-   Sử dụng GitHub để chia sẻ và quản lý mã nguồn.

## 7. Hướng phát triển

-   Cung cấp dữ liệu đầu vào/đầu ra mẫu và mô tả các chức năng chính.
-   Bổ sung kiểm thử và ghi rõ những giới hạn hiện tại.
-   Bổ sung mô hình máy học để phân tích từ dữ liệu đã đọc được từ file csv.
-   Thêm biểu đồ thể hiện những gì phân tích được.
